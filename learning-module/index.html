01 / Physics · 20 minutes

Phase becomes useful through interference.

A state vector is a normalized complex amplitude vector. Measurement returns outcome j with probability |αj|². A global phase eiγ cancels from every such probability. A relative phase changes how amplitudes add after a change of basis.

|+⟩ = (|0⟩ + |1⟩)/√2
|+φ⟩ = (|0⟩ + eiφ|1⟩)/√2
H|+φ⟩ = [(1 + eiφ)|0⟩ + (1 − eiφ)|1⟩]/2
P(0) = cos²(φ/2),   P(1) = sin²(φ/2)

Measuring before the final Hadamard gives 50/50 for every φ. Measuring after it reveals interference. On the Bloch sphere, the relative phase moves an equatorial state around the equator. Multiplying an eigenstate by a global phase leaves its Bloch vector fixed.

Why phase kickback works

Let U|ψ⟩ = e2πiθ|ψ⟩, with θ in turns. A control prepared in |+⟩ creates two coherent branches: do nothing, and apply U.

CU(|+⟩ ⊗ |ψ⟩)
= [|0⟩ ⊗ |ψ⟩ + |1⟩ ⊗ U|ψ⟩]/√2
= [(|0⟩ + e2πiθ|1⟩)/√2] ⊗ |ψ⟩

The target eigenstate is unchanged as a physical state. Its eigenphase becomes a relative phase on the control. The experiment compares evolution with no evolution; it does not directly read an isolated global phase. This is the mechanism behind the warm-up in IBM's phase-estimation lesson.

The only linear algebra you need to reload

Unitary means U†U = I: ideal closed-system evolution preserves lengths and inner products. If U|ψ⟩ = λ|ψ⟩, norm preservation gives |λ| = 1, so λ = eiφ. A Hamiltonian H is Hermitian, H† = H, so its eigenvalues E are real energies. Time evolution links the two: U(t) = exp(−iHt/ℏ). The dagger denotes conjugate transpose; ⊗ combines registers. Measurement and noisy channels need not be reversible.

Predict. If the target is |1⟩ and U = diag(1, eiπ/4), does its Bloch vector move? What phase does the control acquire?
Reveal the answer

The target stays at the south pole. The control acquires relative phase π/4 radians, or θ = 1/8 turns. After one control Hadamard, P(0) = cos²(π/8) ≈ 0.853553. Multiple powers will resolve more information.

A subtle implementation trap. P(φ) = diag(1,eiφ) = eiφ/2RZ(φ). These differ only by global phase when applied alone. Their controlled versions differ by an observable phase on the control. Replacing cp with crz silently changes QPE's eigenphase unless you compensate.
02 / Mathematics · 25 minutes

The register is a finite interferometer.

Let m be the number of counting qubits and N = 2m. Integers k = 0,…,N−1 label the counting basis; qubit j is the bit of weight 2j. The target can contain many qubits, although your original uses one.

|0⟩⊗m|ψ⟩
→ (1/√N) ∑k=0N−1 |k⟩|ψ⟩
→ (1/√N) ∑k=0N−1 e2πikθ|k⟩|ψ⟩
Hadamards create the uniform sum; controlled U2ʲ creates the phase ramp.

Write k = ∑j kj2j. The controlled gates contribute ∏j e2πiθkⱼ2ʲ = e2πiθk. This is why powers of two appear: the binary bits jointly encode every exponent from 0 to N−1.

The inverse QFT tests this ramp against each discrete Fourier frequency y/N:

QFT†|k⟩ = (1/√N) ∑y=0N−1 e−2πiky/N|y⟩
ay = (1/N) ∑k=0N−1 e2πik(θ−y/N)
P(y | θ) = |ay|²,   θ̂ = y/N

For δ = θ − y/N, sum the geometric series using r = e2πiδ. If r ≠ 1, ∑ rk = (1−rN)/(1−r). Taking squared magnitudes and using |1−eix|² = 4sin²(x/2) gives:

P(y | θ) = sin²(πNδ) / [N² sin²(πδ)]
Use the continuous limit P = 1 when δ is an integer.

If Nθ is an integer y*, all the arrows contributing to ay* align. For other y they cancel. If Nθ is not an integer, no bin perfectly matches the ramp and the probability spreads. This is finite-window Fourier leakage. There is no computational basis ket labeled by a noninteger Nθ.

The counting register resembles a discretized time record, but QPE is a coherent computation: its amplitudes interfere before measurement. Its efficiency also depends on preparing the state and implementing controlled powers. A small gate count for the QFT alone does not establish an end-to-end speedup.

Three distinct sources of error

EffectWhat it doesWhat helps
Finite mSets the single-shot grid 1/2m and the ideal Fourier distributionMore coherent evolution / more counting bits
Finite shots SMakes observed frequencies fluctuate around probabilitiesRepeated independent shots; typical frequency SE √[p(1−p)/S]
Physical and model errorChanges the distribution through noise, drift, or approximate evolutionCharacterization, improved control, justified modeling and mitigation

More shots do not refine the single-shot grid. They can improve a continuous parameter estimate obtained by fitting the full likelihood P(y|θ). Keep that statistical inference distinct from returning the modal grid point.

d(θ̂,θ) = min(|θ̂−θ|, 1−|θ̂−θ|)
Expected single-shot error = ∑y P(y|θ)d(y/N,θ)
Success at tolerance ε = ∑y: d(y/N,θ)≤ε P(y|θ)

All phases here are in [0,1). The circular metric respects the equivalence of 0 and 1 turn. Error of the mode and expected error of a random shot are different quantities; report which you mean.

03 / Worked examples · 20 minutes

From a T gate to your unresolved table.

A. Exactly representable: θ = 1/8, m = 3

For U = P(π/4) and target |1⟩, the eigenvalue is eiπ/4 = e2πi/8. The counting controls q₀, q₁, q₂ acquire phases π/4, π/2, π. Their product state encodes e2πik/8. In the inverse-QFT amplitude, y = 1 gives δ = 0, so eight terms add to eight and a₁ = 1. Every other amplitude vanishes.

Measured bits c₂c₁c₀ = 001 → y = 1 → θ̂ = 1/8

Qiskit's displayed bit strings put the highest-index classical bit on the left when you measure qⱼ into cⱼ. The lab's probability index y uses q₀ as its least significant bit. Swaps in the inverse QFT are part of this convention.

05 / Beyond the old project · 45 minutes

Energy is a phase accumulation rate.

The Schrödinger equation iℏ∂|ψ⟩/∂t = H|ψ⟩ has solution U(t) = e−iHt/ℏ for time-independent H. If H|Eⱼ⟩ = Eⱼ|Eⱼ⟩, time evolution multiplies that eigenstate by e−iEⱼt/ℏ. QPE turns this rate of phase accumulation into an energy estimate.

θⱼ = −Eⱼt/(2πℏ) mod 1
Eⱼ = −(2πℏ/t)(θⱼ + ℓ),   ℓ ∈ ℤ
A known energy interval selects the integer branch ℓ.

Two energies separated by 2πℏ/t give the same phase. A prior interval of width less than 2πℏ/t avoids that ambiguity for a fixed base time. You must still handle the phase branch cut consistently; a useful alternative is to shift H by a known reference energy before evolution.

A complete one-spin example

Choose units ℏ = 1, H = Z/2, and t = π/2. This describes a two-level splitting of one energy unit, analogous to an effective spin in a field along z. Since Z|0⟩ = |0⟩ and Z|1⟩ = −|1⟩, the energies are +1/2 and −1/2.

U = e−iπZ/4 = diag(e−iπ/4, e+iπ/4)
|0⟩: θ₀ = −1/8 mod 1 = 7/8 → y = 7
|1⟩: θ₁ = +1/8 → y = 1

With m = 3 both outcomes are exact. Choose the energy interval (−2,2]. Then θ = 7/8 unwraps to −1/8 and gives E = −4(−1/8) = +1/2. Phase 1/8 gives E = −4(1/8) = −1/2. Here crz(t * 2**j) is the correct controlled evolution because RZ(t) = exp(−itZ/2).

What if you cannot prepare an eigenstate?

|ψ⟩ = ∑j cⱼ|Eⱼ⟩
P(y) = ∑j |cⱼ|² P(y | θⱼ)

The joint state becomes ∑ⱼcⱼ∑ᵧaᵧ(θⱼ)|y⟩|Eⱼ⟩. Ignoring the target removes cross terms because distinct energy eigenstates are orthogonal. If the phases are exactly resolved, measurement projects the target into the associated energy eigenspace. At finite resolution, different energy components can survive in the conditional state.

For target |+⟩ in the spin example, the histogram has probability 1/2 at y = 1 and 1/2 at y = 7. Its mean energy is zero, but QPE does not return a zero-energy eigenvalue. It samples the spectrum with weights set by the initial overlaps. If ground-state overlap probability is p, the probability of seeing it at least once in S independent preparations is 1−(1−p)S, assuming perfect identification.

Exercise: expose the state-preparation cost

Let p = 0.01. How many independent preparations are needed for at least 95% probability of observing the ground state?

Answer: S ≥ ln(0.05)/ln(0.99), so S = 299. That is before adding misclassification and hardware error. Preparing a useful input is part of the algorithm's cost.

Next: two interacting spins

H = J Z₀Z₁ + h(X₀ + X₁)
Example: J = 1, h = 1/2
Eigenvalues: −√2, −1, +1, +√2

The ZZ term couples the spins; the transverse X terms drive transitions. The terms do not all commute, so simulating evolution becomes an actual problem. In the Bell basis, one pair of states has energies ±J, and the remaining 2×2 block is [[J,2h],[2h,−J]], giving ±√(J²+4h²).

First diagonalize the 4×4 matrix classically to establish ground truth. Implement its exact exponential and check QPE's mixture against known eigenvalues and overlaps. Then replace exact evolution with the first-order product formula [e−iJZZt/re−ihX₀t/re−ihX₁t/r]r. Compare to the exact result as r increases. This extension is an exercise, not an implemented claim in the supplied lab.

Track the right cost. A register of m controls uses powers up to 2m−1. If evolution costs grow linearly with time, total evolution per shot is (2m−1)t and the longest segment is 2m−1t. Energy-bin spacing is 2πℏ/(t2m). More precision demands longer coherent evolution. Your known phase gate can compress each power into one rotation; a general Hamiltonian cannot be assumed to do that cheaply.
06 / Research direction

Reliability can become the scientific question.

A productive niche for your SRE experience is deciding when a quantum estimate is trustworthy under changing experimental conditions.

Observability, experiment provenance, scheduling, failure analysis, and resource accounting transfer well. The added physics is identifying which assumptions make an estimator valid, then measuring what happens when those assumptions fail. A reproducible platform supports a scientific result; a platform by itself does not establish novelty.

Recover

Derive and reproduce the ideal distributions. Explain every discrepancy with your 2020 table.

Surpass

Estimate an energy spectrum, model imperfect input states, and account for evolution cost.

Investigate

Measure reliability under drift with explicit baselines and held-out experiments.

A concrete candidate question

At fixed total evolution budget, when does slowly drifting phase make a stationary phase estimator overconfident, and can a drift-aware policy restore calibrated uncertainty without excessive cost? This is a proposal to investigate, not a claim of novelty. Consistency checks for robust phase estimation already exist; read Russo and colleagues and inspect pyRPE before choosing the contribution.

Start with a one-control interferometric experiment. For depth k, offset β, outcome b ∈ {0,1}, and visibility v(k), use the synthetic likelihood:

P(b | θₛ,k,β) = ½[1 + (−1)bv(k)cos(2πkθₛ + β)]
v(k) = exp(−kt₀/T₂)
θₛ₊₁ = (θₛ + μΔτ + σ√Δτ ξₛ) mod 1,   ξₛ ∼ Normal(0,1)

Here t₀ is base coherent evolution time, T₂ a phenomenological coherence scale, and Δτ is wall-clock time between experiments. μ and σ model drift between shots; assume phase is approximately constant within each shot. This deliberately simplified model must be checked against any hardware data before physical claims. Separate phase in turns from the radian phase used by many external libraries.

A stationary Bayesian estimator updates p(θ|D) ∝ p(θ)∏ₛP(bₛ|θ,kₛ,βₛ). A tracking estimator first propagates the posterior through a drift transition model, then incorporates the new likelihood. Both can produce narrow posteriors; only repeated synthetic trials with known truth reveal whether their intervals cover the target at the advertised rate.

DecisionA concrete initial protocol
TargetCurrent θ at the end of a run; define circular intervals and error
BaselinesStationary inference, periodically restarted inference, drift-aware filtering; include published RPE consistency checks when comparing claims about RPE
BudgetMatch B = ∑ₛkₛ, report shots, maximum k, wall-clock duration, and rejected/restarted work separately
SweepZero drift plus increasing μ and σ; finite coherence; several true phases including wraparound

ReplicationStart with 200 independent trajectories per condition; increase based on precision needed. At true coverage 0.95, 200 trials give SE ≈ 0.0154

The decisive figure could show interval coverage versus drift, with matched budgets and uncertainty bars. Include zero-drift performance to expose the price of robustness. Ablate drift propagation, restart rules, and scheduling separately. Randomize or interleave hardware conditions so changes over time are not confused with algorithm improvements.

What would make this publishable?

A new, well-supported observation or method: for example, an uncharacterized failure regime of an existing estimator, a defensible reliability criterion, or a reproducible improvement over strong baselines. A small simulator study can be meaningful when the question is precise and the result survives independent reproduction. Whether it merits publication depends on novelty, evidence, and comparison to current literature.

Before building much infrastructure, write a one-page claim and search for prior drift-aware estimation, adaptive sensing, nonstationary Bayesian inference, and RPE consistency work. Read the closest methods in full, reproduce one result, and revise your question. Seek critical feedback from an author or an open-source community once you have a specific result to discuss.

Read with an experiment in mind.

  1. Recover the derivation · IBM Quantum Learning. The phase-estimation procedure. Begin with the kickback warm-up and the inverse-QFT construction. Recreate: predict the one-control probabilities and the three-bit T-gate result without running a circuit. Then verify with this lab.
  2. Connect phase to calibration · Kimmel, Low & Yoder (2015). Robust Calibration of a Universal Single-Qubit Gate-Set via Robust Phase Estimation. Read the problem statement and noise assumptions before the proof. Recreate: a synthetic rotation-angle estimation experiment as maximum sequence length increases; report total gate applications, not just shots. This is a theory-to-simulation learning reproduction.
  3. See the physical experiment · Rudinger et al. (2017). Experimental demonstration of cheap and accurate phase estimation. The experiment uses trapped-ion gate rotations.   4. Ask when to stop trusting an estimate · Russo et al. Consistency testing for robust phase estimation, with pyRPE source and Sandia's overview.   5. Learn adaptive statistical estimation · Quantinuum phayes. Repository and example notebooks; companion paper Demonstrating Bayesian Quantum Phase Estimation with Quantum Error Detection (Yamamoto et al., 2023). Recreate: run the repository's synthetic likelihood example, track posterior width, and assess repeated-trial coverage. Account for radians versus turns. Quantum error detection in the paper adds requirements beyond this synthetic exercise.
  6. Understand the depth tradeoff · Ni, Li & Ying (2023). On low-depth algorithms for quantum phase estimation, published in Quantum 7, 1165. Recreate: first implement a small one-eigenphase instance from the method, then vary initial-state overlap and compare maximum evolution time with total evolution time. Read after you are comfortable with the Hamiltonian exercise; overlap assumptions are central.
  7. Explore characterization infrastructure · Sandia pyGSTi. Source, examples, and documentation. This broader gate-characterization toolkit is an optional engineering path. Recreate: one small tutorial's simulated data and report, then inspect how experiment definitions and model fits are recorded. It is a separate project, not a prerequisite for this module.
